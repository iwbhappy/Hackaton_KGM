# Выполнение раздела 10

Шаги выполняются последовательно; каждый завершённый шаг имеет отдельный коммит.

| Шаг | Проверка | Результат |
|---|---|---|
| 0 — каркас | pytest, запуск run.bat, GET /health, шесть таблиц SQLite, локальный Chart.js | выполнен |
| 1 — стенд | 3 теста; curl с --resolve для soon; openssl s_client: у nochain один сертификат | выполнен |
| 2 — парсер | 28 тестов: форматы, IPv6, CIDR, BOM, CSV с двумя разделителями, дубликаты, лимиты и ошибки строк | выполнен |

Уточнения ТЗ:
- Для недоступности `dead.lab.local → 127.0.0.2` стенд должен слушать `127.0.0.1`, а не все локальные адреса. Будет предусмотрен параметр bind.
- Пороги должны удовлетворять `info > warning > critical ≥ 0`. Проверка warning=50 после info=40 потребует одновременно вернуть info=60.
