## Слайды 11–13 — ответы на вопросы

**Почему 91, а не 90, как в ТЗ?**
В ТЗ пример иллюстративный. У нас прозрачная формула: 70 × 1,3 = 91. Уровень тот же — Critical. Веса хранятся в настройках.

**Как проверяется цепочка?**
OpenSSL с системным хранилищем Windows и корпоративными корневыми CA. По коду ошибки различаем самоподписанный, неполную цепочку и недоверенный корень.

**Как вы получаете истёкший сертификат, если он не проходит проверку?**
Два подключения. Первое без проверки — забираем сертификат в любом состоянии. Второе строгое — получаем вердикт о доверии.

**Как проверяется имя?**
По RFC 6125: если есть SAN, поле CN не смотрим. Wildcard покрывает ровно один уровень имени.

**Что при сканировании по IP?**
Без имени сервер отдаёт сертификат по умолчанию. Поэтому рекомендуем DNS-имена, а IP сверяем с IP в SAN.

**Не будет спама уведомлениями?**
Нет. Одно сообщение на порог для каждого сертификата и канала. Заменили сертификат — отсчёт заново.

**Что если сертификат заменили?**
Меняется отпечаток, в карточке сервиса видна история замен.

**Безопасно сканировать продакшен?**
Да. Только рукопожатие, как у браузера. Параллельность и таймауты настраиваются. Скан подсетей лучше согласовать с SOC.

**Масштаб?**
32 параллельных подключения, 50 целей примерно за 2 секунды, до 2048 целей за скан. Для тысяч — очередь задач и PostgreSQL.

**Чем лучше Key Manager Plus?**
Мы не заменяем полноценную систему управления сертификатами. Наше решение бесплатное, разворачивается за минуты, риск объясним, проверки добавляются под свои правила.

**Почему не Prometheus и Grafana?**
Они дают метрики, но не инвентарь, причины и рекомендации. Экспорт метрик — в планах.

**Откуда владельцы?**
Сейчас из CSV и вручную в интерфейсе. Дальше — из Active Directory или CMDB.

**Другие порты и протоколы?**
Порт задаётся в цели: `host:port`. SMTP и LDAP через STARTTLS — следующий сборщик.

**Проверяете отзыв сертификата?**
Пока нет. OCSP и CRL — в планах.

**Есть авторизация?**
В MVP нет: приложение слушает только 127.0.0.1. Роли и SSO — следующий шаг.

**Это искусственный интеллект?**
Нет. Прозрачные правила и формула. Каждый балл объясним.

**Как добавить новую проверку?**
Одна функция в `app/analysis/checks.py` и одна строка в списке `CHECKS`.

**Работает без интернета?**
Да. Сканирование и отчёты — полностью офлайн. Интернет нужен только для внешних уведомлений.

**Какой экономический эффект?**
Пока не измеряли. Хотим проверить на пилоте: сколько проблем нашли и сколько исправили до истечения.
