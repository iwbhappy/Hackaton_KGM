# Материалы для защиты Certificate Radar

Формат: жюри хакатона и руководство компании, 5 минут, 7 слайдов.

- **Certificate_Radar_Pitch.pptx** — редактируемая презентация; речь также включена в заметки слайдов.
- **Certificate_Radar_Pitch.pdf** — резервная версия для показа без PowerPoint.
- **SLIDE_NOTES.md** — текст к каждому из 13 слайдов HTML-презентации, демо по шагам и ответы на вопросы; удобно читать с телефона.
- **PITCH_SCRIPT.md** — речь с таймингом ровно на 5 минут и вариантом краткого ответа.
- **PROJECT_GUIDE.md** — подробное объяснение простым языком, нюансы и ответы жюри.
- **PROJECT_GUIDE.html** — тот же разбор для чтения в браузере и печати.
- **PROJECT_GUIDE.pdf** — версия разбора для чтения с телефона или отправки.

Откройте PowerPoint, нажмите F5. Живой показ приложения на слайде 4 занимает его 50 секунд, а не добавляется к пяти минутам. При проблемах со стендом используйте встроенный скриншот.

Материалы основаны на текущем коде и PROGRESS.md, без неподтверждённых данных о внедрении и экономии. Скриншот относится к изолированному лабораторному демо. Рабочие данные приложения при подготовке материалов не изменяются.
